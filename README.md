🍕 Pizza Sales Analysis

A data analytics project focused on analyzing pizza sales data using Microsoft Excel and MySQL.

📊 Project Overview

This project analyzes pizza sales data to understand sales performance, revenue, order trends, pizza sizes, categories, and top-selling pizzas.

🛠️ Tools & Technologies

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- MySQL

📈 Excel Dashboard

The Excel dashboard includes:

- Total Sales and KPI analysis
- Sales and order analysis
- Pizza size analysis
- Category-wise analysis
- Daily sales trend
- Top-selling pizzas
- Interactive slicer for data exploration

🗄️ SQL Analysis

The SQL file contains queries used to analyze the pizza sales data and answer different business-related questions.

📁 Project Files

- "Pizza_Sales_Analysis.xlsx" — Excel dashboard and data analysis
- "Pizza_Sales_Analysis.sql" — SQL queries used for analysis
